# 北辰 · 高一选科探索(v2 重构版)

> 譬彼北辰，居其所而众星共之。——《论语·为政》

北辰是一款面向高一学生的 AI 选科陪伴网页。它不从"哪个组合更热门"开始，而是通过一场谈心陪学生回看学科手感、开窍与挫败、真正的热爱、理想生活、家庭声音和个人边界，最后点亮一张属于自己的「北辰星图」。领航模式（每轮给引导与选项）固定十轮；夜航模式（自由畅聊）不设轮数上限，聊到信息足够时随时可以点亮星图。在线体验见部署地址(由 GitHub Pages 发布)。

## 两种聊法(v2 新增)

进入正式对话前，学生可以选一种适合自己的节奏：

| 模式 | 适合 | 体验 |
| --- | --- | --- |
| **夜航(OPEN)** | 愿意多说、想被认真听的学生 | 没有选项、不下框架，辰像朋友一样开放式提问，每轮自己打字回答 |
| **领航(GUIDED)** | 不知道说什么、想要引导的学生 | 每轮给出思考的"扶手"和 4 个具体选项，点一下就能继续，随时可以补充自己的话 |

两种模式：同一张标准格式的星图、每次验证 3 次生成额度；随时可在设置里查看剩余次数。部署与调参见《操作执行清单.md》。

## 对话格式约定(前端与提示词的共同契约)

- 每条回复固定两段：第一段回应学生，第二段提问；
- 第二段以「想问你：」开头——这只是版式记号(前端靠它可靠分段)，界面上不显示；
- 领航模式下，每轮末尾是标准格式 `【选项】A||B||C||D`，前端解析为快捷按钮；
- 夜航模式绝不输出【选项】；第 5 轮起每轮回复后出现「点亮星图」入口，点击先确认额度消耗，学生自主决定生成时机，生成后可继续聊、可再次点亮(再扣一次额度)；
- 星图报告是严格标签格式(【称号】【方位】【星值】【一句话】5×【星卡】【组合】【专业】【寄语】)，解析器宽容降级、绝不死循环。

## 架构

```
浏览器(GitHub Pages, 零密钥)
   │  POST /verify /run/complete /chat/completions
   ▼
腾讯云 SCF Web Function(beichen-qianfan-mini, 本仓库 scf-relay.js)
   │  Bearer 千帆Key(仅存云端环境变量)
   ▼
百度千帆 Token Plan 个人版专属端点(/v2/tokenplan/personal) · GLM-5.2
```

- 星门：TOTP 动态码(6 位)，验证后 7 天有效(令牌仅存 sessionStorage)
- 额度：一次验证 3 次完整谈心(以星图生成为准)，`/run/complete` 幂等记账
- 思考：GLM-5.2 固定 max 档；思考预算分档——星图轮 4096 / 日常轮 2048
- 星图解析：宽容降级渲染(组合支持"物化生"等口语缩写)，永不卡死

| 文件 | 说明 |

| `index.html` | 唯一前端页面(星门/介绍/模式选择/双模式谈心/自适应星图/设置) |

| `操作执行清单.md` | 部署/调试/密钥/工具的唯一交棒文档(不提交到仓库，仅本地保存) |
