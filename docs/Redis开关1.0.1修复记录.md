# Redis 开关 1.0.1：关闭可靠性与桌面反馈

修复旧流程中 GitHub 哨兵同步失败就退出、Redis 尚未关闭的问题；补充云 API 暂时性断连的安全重试。旧版没有日志，原失败具体报错无法追溯，因此不将其唯一归因于网络故障。

## 改进

- GitHub 故障不阻断关闭，关闭与哨兵结果分别报告。
- 只读云 API 有限重试；删除响应丢失后先核实状态，不重复提交。
- 真正确认删除才显示成功，取消、失败、附属警告区分处理。
- 桌面菜单保留结果并返回菜单；新增“4 查看操作记录”，脱敏日志自动保存。
- 同机操作互斥，开启只确认一次。
