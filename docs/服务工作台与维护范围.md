# 北辰服务工作台与维护范围

2026-10-11：学生应用和云函数为 v2.9.4，模型能力版本为 v2.9.1，维护工作台版本为 v1.5。

## 维护者下载入口

工作台在 [私有交接库发行页](https://github.com/yusheng266186-beep/beichen-handover/releases/tag/workbench-v1.5)，提供独立 HTML 和附使用说明的 ZIP。需要有交接库访问权限的 GitHub 账号；下载后用浏览器打开、保持联网。仓库根目录 `北辰后台工作台.html` 同步保存当前版本，可通过“下载原始文件”获取。

公开北辰库保存学生应用源码、模型能力配置与部署指南；私有交接库保存工作台、操作流程、Actions 运维工具和受控配置。工作台包含维护操作连接，应保持私有。模型及腾讯云密钥保存在云端配置和私有 Secrets，学生页面不接收这些值。

## 当前维护功能

1. 查看 Redis 状态、服务就绪、哨兵与云端核验时间。
2. 创建／复用或销毁按量 Redis，并联动哨兵。关闭会清空云端会话和额度状态；快照只保存重建参数。
3. 在 DeepSeek 官方、Wefucke GLM、Wefucke GPT 三个入口切换已适配模型。
4. 设置模型原生默认思考强度；GPT-6 Sol 的深思档对应 max。学生自己的强度选择优先。
5. 追踪实际 GitHub Actions 任务和结果，防止重复提交；运行核验失败保留或恢复旧模型配置。

工作台保留近期参数验证缓存、实际上游连通检查、运行配置回读和每两秒任务刷新。云端任务关闭页面后继续执行。进行中的学生请求可能受模型配置重载影响，安排在空闲时操作。

## 当前产品范围

暂不建设用户统计、账号管理及长期分析数据库。原工作台的虚构用户、登录／使用记录、图表和 CSV 导出已移除，现有 Redis 继续只用于短期业务状态。

真实操作记录来自 Actions，不是学生访问统计。以后需要增加分析功能时，再确定稳定身份、统计口径、独立持久存储、管理员权限和运行预算；不能把 Actions 记录或验证码会话当作真实注册用户。

本次工作台整理不需要更新生产函数代码，也不新增收费分析资源。实时运行配置以工作台核验结果为准；旧统计演示可从交接库 Git 历史找回。
