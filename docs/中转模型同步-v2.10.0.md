## 对话与星图

完整 system、user、assistant 原话进入目标接口；报告提示、历史分段、修复及接续逻辑保持。原有 Wefucke／DeepSeek 报告预算保留，新组按原生模型能力配置。支持 Max 的 GPT-6 Sol、Opus 5.5 保留原生 Max；其他模型显示实际最高档位，能力不明的别名不强制传入 Max。

Claude 的正文及思考增量、Responses 的正文及摘要事件转换为学生页面已有 SSE 格式。中文及 emoji 可跨任意网络字节边界；终态中的重复正文不重复输出；达到输出上限继续传递 `length`。缺终态、上游报错及不一致正文按失败处理，释放预占，避免半张星图被结算成成功。

## 验证记录

- 本地 Node 回归 55 项：53 通过，2 项实际 Redis 测试交由带 Redis 服务的仓库 CI。
- 私有维护工具 Python 回归 47 项通过，工作台脚本回归 5 项通过。
- ByteCat 原CC／新CC Opus 5.5、ByteCat GPT-6 Sol、Wefucke Muse 的最高档真实流式调用通过；使用的探测体和流转换器与云端同源。
- 合成学生资料的完整聊天／星图测试：新CC Opus 5.5 返回 5 张星卡、7 个专业及寄语；GPT-6 Sol Max 返回 5 张星卡、6 个专业及寄语，两份均通过现有星图完整性解析。GPT 首次长报告请求超时，复测完整返回约 256 秒；保留失败释放与重试机制，没有自动降低强度或切换供应商。
- 云端回读确认 v2.10.0 与模型能力版本一致；当前 Wefucke GPT-6 Sol／深思档、Redis 关闭、TOTP 30 秒换码／100 秒接受期及请求限额保持。

这些测试验证接口与完整生成链路，不代表逐一调用过所有 135 项，也不替代实际院校当年的专业要求核验。切换时会检查目标模型所选档与最高档，失败保留当前配置。

## 维护与已知限制

工作台 v1.6 支持按模型名称或 ID 筛选，可在 Redis 关闭时切换模型。没有增加统计数据库或用户管理后台。

Command Code 已出现余额不足，千帆套餐已过期；保留配置便于后续续费，不能绕过套餐限制。GPT-5.4 Compact 曾返回上游 503 过载，切换前会重新实测。模型目录查询成功仅代表目录可读。

部署前保存私有代码包与全量环境快照；失败可恢复原代码和环境。公开仓库不保存工作台操作凭据、腾讯云凭据或模型 API 密钥。工作台只通过私有交接库提供下载。
