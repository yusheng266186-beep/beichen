# 参考问答动画修复 · v2.9.6

2026-10-11。本次仅修复参考数据问答开合动画，并同步运行版本与维护记录。其他完善方向只供用户评估，没有实施。

旧版 details 展开时立刻撑开布局，再独立播放文字位移／浮现，收起则直接跳回；问题整行的按压缩放进一步放大不协调感。新版为答案增加无内边距的高度容器，按实际内容测量展开高度，统一控制开合动画。展开 240ms、收起 190ms，使用无过冲缓动；文字保留原位，不单独漂移，问题按压仅作颜色反馈。

连续点击先读取当前画面高度，再取消旧动画并反向接续，旧完成回调不会覆盖新状态。动画完成释放临时高度，答案恢复自适应排版；关闭数据面板、窗口尺寸变化或减少动态效果偏好改变时收整动画。减少动态效果或不支持 Web Animations API 时直接开合。保留 details／summary 原生结构、键盘与无脚本降级。

十条问答正文已与 v2.9.5 逐字核对，没有内容变化。浏览器检查展开／收起、连续双击、回车、空格及长答案显示。本地完整回归 47 项：45 项通过，2 项真实 Redis 集成由 CI 执行；内联脚本语法和公开库密钥扫描通过。
